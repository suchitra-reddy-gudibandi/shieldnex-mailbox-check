Results

Every address gets one of three results.

Delivered
The mail server confirmed the mailbox exists.
Bounce
The address can't receive mail: bad format, a domain that doesn't exist, or a mailbox the server rejects.
Unknown
The domain takes mail, but its server won't say whether this mailbox exists. Many large providers behave this way.

    How each address is checked
    1. Format. One @ sign, a valid name before it, a valid domain after it.
    2. Domain. The domain must exist in DNS.
    3. Mail server. The domain must publish a mail server (MX record) and not opt out of email.
    4. Mailbox. We connect to that server and ask whether it would accept the recipient. We also test a made-up address on the same domain, because some domains say yes to everything. Those are marked unknown.

    Some hosting providers block outgoing connections to mail servers. When that happens, step 4 is skipped and the page says so above. Addresses on working domains are then marked unknown, never delivered.
